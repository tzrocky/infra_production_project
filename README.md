# infra_production_project
infra production project


🧱 <b>1. Create a virtual environment</b>

Navigate to your project folder in the terminal, then run:
      
      python -m venv venv
      
This creates a folder named venv containing an isolated Python environment.


▶️ <b>2. Activate the virtual environment</b>

<b>On macOS / Linux:</b>
    
      source venv/bin/activate
    
<b>On Windows (CMD):</b>

      venv\Scripts\activate
      
<b>On Windows (PowerShell):</b>

      venv\Scripts\Activate.ps1
    
Once activated, you’ll see (venv) in your terminal prompt.


📦 <b>3. Install dependencies (optional)</b>

If your script needs packages:

      pip install -r requirements.txt

or install manually:

      pip install requests

🚀 <b>4. Run your Python script</b>

      python script.py
